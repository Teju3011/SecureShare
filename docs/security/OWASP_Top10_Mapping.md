# OWASP Top 10 (2021) Compliance & Mitigation Mapping

| OWASP Category | Threat Description | SecureShare Mitigating Control | Implementation Details & Test Ref |
| :--- | :--- | :--- | :--- |
| **A01: Broken Access Control** | Unauthorized access to user files, BOLA, IDOR, privilege escalation. | **SC-09, SC-10** | Database joins enforce tenant ownership before streaming or deleting files. Role checks in middleware (`require_admin`). Tested by `tests/security/test_bola.py`. |
| **A02: Cryptographic Failures** | Exposure of plaintext files or passwords, weak cipher modes. | **SC-01, SC-07, SC-08** | Passwords hashed using Argon2id. Files encrypted at rest with AES-256-GCM using unique 96-bit random IV per file and 128-bit auth tag. Tested by `tests/security/test_integrity.py`. |
| **A03: Injection** | SQL injection, cross-site scripting (XSS), command injection. | **SC-04, SC-14** | SQLAlchemy ORM parameterized queries exclusively. Filename sanitization via regex. React auto-escaping for frontend rendering. Tested by `security/fuzzing/test_auth_fuzz.py`. |
| **A04: Insecure Design** | Lack of threat modeling, zip bomb resource exhaustion, malware distribution. | **SC-04, SC-05, SC-06** | Complete STRIDE threat model. 6-stage malware scanner with ClamAV and entropy check. Automated file quarantine air-gap. Tested by `tests/security/test_file_upload.py`. |
| **A05: Security Misconfiguration** | Unhardened servers, default passwords, missing HTTP security headers. | **SC-14** | Non-root Docker container (UID 10001). Security headers injected: `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `HSTS`. Tested by ZAP baseline scan. |
| **A06: Vulnerable and Outdated Components** | Exploitation of unpatched third-party Python/Node libraries. | **SC-14** | Automated dependency audits in CI/CD pipeline via `pip-audit`, `Safety`, and `npm audit`. Verified in GitHub Actions workflow. |
| **A07: Identification and Authentication Failures** | Brute force credential guessing, credential stuffing, session hijacking. | **SC-01, SC-02, SC-03, SC-15** | Sliding-window IP and account rate limiting (5 req/min). 5-attempt account lockout. Short-lived 60-minute JWT access tokens. RFC 6238 TOTP MFA. Tested by `test_authentication.py`. |
| **A08: Software and Data Integrity Failures** | Unauthorized code or data tampering, insecure deserialization. | **SC-07, SC-12** | AES-256-GCM authentication tag verification on download. Tamper-evident SHA-256 hash chaining of audit logs. Code signing in CI/CD. Tested by `test_integrity.py`. |
| **A09: Security Logging and Monitoring Failures** | Lack of audit logs, repudiation of actions, undetected breach activity. | **SC-12, SC-13** | Immutable audit trail capturing actor IP, timestamp, and action. Automated cryptographic verifier detecting any row modification. SOC dashboard. Tested by `test_audit_logging.py`. |
| **A10: Server-Side Request Forgery (SSRF)** | Exploitation of backend server to query internal networks or metadata endpoints. | **SC-04** | Scanner engine operates purely on isolated local byte streams. Zero external URL fetching permitted in upload or scan workflows. Verified in code review. |
